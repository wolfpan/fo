# zen/compile · 人格编译产物（M0）

由 huineng-perspective-skill（146KB 源包）一次性编译而成。**运行时只加载本目录产物，源包不再进 prompt。**

## 资产清单

| 文件 | 用途 | 运行时位置 |
|---|---|---|
| `kernel.md` | 人格内核：身份、铁律、应答四步、表达基因、危机护栏、示范 6 条 | Tier 0 常驻（全用户共享，逐字节一致，吃前缀缓存） |
| `model-cards/01–06` | 六张心智模型卡，frontmatter `tags` 为检索主题标签 | Tier 1 按题检索，命中 1–2 张注入 |
| `fewshot.json` | 20 组机锋问答：`q_modern`（现代问法，检索用）/ `q_classical`（原典场景）/ `a`（内核口吻示范） | Tier 1 动态 few-shot，相似度 top 1–2 组注入 |

## 组装顺序（缓存关键）

```
[kernel.md 全文]                        ← 静态，跨用户缓存
——
【参学簿】话头 + 画像 + 记忆召回         ← 单用户半静态
【经证】sutra_chunks 检索原文 + 出处     ← 动态
【机缘】persona_kb 命中的模型卡/问答    ← 动态
【近几轮】对话                          ← 动态
【本轮问】
```

kernel.md 内已写明对各附注段的使用规则（引经只认【经证】段等）。

## 铁则

- `fewshot.json` 的 `a` 是编译产物，**不是经文**，不可作引文；引文只认运行时【经证】段。
- 换 embedding 模型不影响本目录；改人格只改本目录并重跑 M1 入库脚本。
- 版本：2026-09-28 编译；源料：huineng-perspective v1（2026-06-10 调研）。
